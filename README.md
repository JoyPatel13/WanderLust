

# Wanderlust 🌍

Wanderlust is a full-stack travel accommodation web application inspired by Airbnb, where users can explore destinations, create property listings, upload images, and share reviews. The platform provides a seamless and responsive user experience with secure authentication and dynamic CRUD functionalities.

## Features ✨

* User authentication & authorization
* Create, edit, and delete property listings
* Upload and manage property images
* Add reviews and ratings
* Responsive and user-friendly UI
* RESTful API integration
* Secure session handling and validation

## Tech Stack 🛠️

* **Frontend:** HTML, CSS, JavaScript, Bootstrap/Tailwind
* **Backend:** Node.js, Express.js
* **Database:** MongoDB & Mongoose
* **Authentication:** Passport.js
* **Cloud Storage:** Cloudinary
* **Other Tools:** REST APIs, Git, GitHub
